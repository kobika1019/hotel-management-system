## 📖 About the Project

Blue Moon Hotel Management System is a web-based project developed to manage hotel activities easily.

Customers can view available rooms and make room bookings through the website. The admin can manage rooms, customer details, and bookings.

This system helps to reduce manual work and makes hotel management easier.

##  Project Objectives

- To develop a simple and user-friendly hotel website.
- To allow customers to register and log in.
- To display room details and prices.
- To allow customers to book rooms.
- To manage customer and booking details.
- To help the admin manage rooms and bookings.
- To store all details in a MySQL database.

## ✨ Main Features

### Customer Features
- Register and log in.
- View available rooms.
- Check room details and prices.
- Book rooms.
- View booking history.
- Request booking cancellation.

### Admin Features
- Admin login.
- View dashboard details.
- Add, edit, and manage rooms.
- Manage room types.
- View customer bookings.
- Update booking status.
- View booking reports.

- Password hashing.
- Prepared statements for database queries.
- Form validation.
- Session-based login.
- Different access for admin and customers.
- Checking booking dates to avoid room booking conflicts.
